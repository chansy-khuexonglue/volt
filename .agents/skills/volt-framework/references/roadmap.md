# Roadmap

1. Core: Bun server, static/dynamic router, response helpers, errors, shutdown.
2. Type safety: route inference, schema adapters, type tests.
3. Hot path: middleware precomposition, serializer experiments, repeatable Elysia benchmarks.
4. Architecture: optional modules, DI, plugin API.
5. Security: auth, CORS, rate limits, logging, limits and audit tests.
6. Integrations: WebSocket, streaming, multipart, databases, OpenAPI.
7. Developer experience: CLI, templates, docs, testing utilities.
8. Stabilization: compatibility matrix, fuzzing, benchmark regression gates, semver release.

At each phase deliver a runnable example, tests, measured performance when applicable, and release notes.
